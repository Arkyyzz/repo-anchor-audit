# Claude for Open Source : vérification du 8 novembre 2026

Les deux pages officielles consultées annoncent **Claude Ultra pendant six mois**. La dénomination actuelle diffère de la demande initiale « Max ». Aucune acceptation ni disponibilité de place n'a été vérifiée pour une personne donnée.

## Profils annoncés

Une voie suffit pour être considéré. Les nombres ci-dessous concernent une activité réelle, pas les résultats d'un dépôt de démonstration.

| Voie | Critère publié |
| --- | --- |
| Mainteneur | Projets maintenus : au total ≥500 dépôts dépendants **ou** ≥100 paquets dépendants, selon GitHub ou un registre public. |
| Auteur de paquets | Au total ≥200 000 téléchargements mensuels sur les registres publics. |
| Contributeur central | Committer ou mainteneur répertorié d'un projet de fondation ou de langage reconnu. |
| Contributeur actif | ≥100 PR fusionnées dans des dépôts publics non possédés, pendant les 12 mois précédents. |
| Communauté | Un dépôt maintenu avec ≥20 contributeurs externes uniques ayant des PR fusionnées dans les 12 mois précédents. |
| Infrastructure critique | Un dépôt maintenu avec un score OpenSSF criticality ≥0,4. |
| Impact de l'écosystème | Voie discrétionnaire : expliquer une dépendance significative de l'écosystème envers son travail. Aucun seuil numérique ne garantit l'acceptation. |

Source : [page officielle du programme](https://claude.com/contact-sales/claude-for-oss).

## Ce que cela implique pour ce projet

**État établi :** cette livraison contient du code local, des tests et des documents. Elle n'établit ni publication publique, ni adoption, ni contribution acceptée par un autre projet. L'âge du compte, la résidence, le rôle et l'historique de l'utilisateur restent inconnus.

Un nouveau dépôt peut devenir utile. Il ne prouve pas aujourd'hui un impact significatif sur l'écosystème. Si vous avez déjà une activité pertinente, commencez par ses preuves vérifiables. Sinon, publiez et maintenez le projet pour ses utilisateurs avant d'envisager une candidature. Aucun calendrier d'adoption ne peut être promis.

Le formulaire interactif n'a pas été rempli et aucune connexion GitHub n'a été effectuée. Le parcours et les informations à préparer ci-dessus viennent des conditions écrites. Recontrôlez les pages au moment de candidater ; aucun compteur de places disponibles n'a été établi.

Préparation : [dossier de candidature](CANDIDATURE.fr.md) et [journal des preuves](PREUVES.fr.md).
